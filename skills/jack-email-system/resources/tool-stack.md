# Tool Stack & Costs

Run a working system for **under $100/month** to start. Do NOT cheap out on data or software — the fastest way to kill a campaign is bad data or the wrong tool. None of these are endorsements; pick equivalents you trust.

## Core stack (required)

| Need | Recommended | Cost |
|---|---|---|
| Sending software (mailboxes, sequences, unibox, warm-up, inbox placement) | **Instantly.ai** (best). Alts: Smartlead, Reachinbox | from ~$37/mo |
| Lead data | **Apollo** (free acct) → **trustedleads.io** to scrape+verify | ~$50 / 10k leads |
| Domains | **Spaceship** (bulk, cheap .com) | ~$10/yr each |
| Mailboxes | **Google** via a reseller/setup service | ~$3/mo each |

Starter math: $37 software + $50 leads + mailboxes ≈ **<$100/mo** for 10k outreach.

## Why Instantly (the sending tool that matters most)

- Highest-quality warm-up pool; excellent deliverability.
- **Inbox placement testing + auto-rotation built in** (game-changer — was manual before).
- Uses its data to skip likely-bounce / likely-spam / hostile leads.
- Best **unibox** + AI reply suggestions; strong API; provider matching, bulk mailbox edit.
- Consolidates tools under one roof — the market is consolidating to 1–2 winners; switching tools later is painful, so choose for the long term.
- **Warning:** don't use a sending tool's own done-for-you mailbox setup — you get locked into their ecosystem and can't move warmed mailboxes out. Use an independent setup service.

## Hard "don't" list

- No cheap/lifetime lead databases (LeadRocks etc.) — trash data.
- No lifetime-deal sending software — they're cheap because they're not there yet (warm-up pools burn you).
- No unmanaged-IP SMTP as your only system.
- No AI writing your whole email or building your whole list.
- Exception where cheap is fine: **email verification** tools are mostly equivalent — an AppSumo verifier is OK.
